# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.
Report them privately through GitHub: **Security** tab -> **Report a vulnerability**.

You can expect an acknowledgement within 3 working days.

## Supported versions

Only the latest released version receives security fixes.

## Secrets

This repository must never contain real passwords, tokens or keys.
Use environment variables, and keep real values in your secret store.
